# 地球卫星全息镜像 · ORBITAL MIRROR

一个**全息风格**的三维地球，实时显示全球在轨卫星的位置与状态。
可随时查看卫星在哪、有多少颗、属于哪些国家和公司、承担什么类型的任务。

V1 基线已备份：同级目录 orbit-holo-BACKUP-v1-20261020（含 .zip）。

## 快速开始

1. 安装 Node.js 18+（本项目零依赖，无需 npm install）。
2. 双击 启动.bat，或执行：

    node server.mjs --port 5180

3. 浏览器打开 http://127.0.0.1:5180/

首次启动会从 CelesTrak 拉取星历（约 4 秒），之后走本地缓存秒开；缓存 6 小时过期，也可点右上角「刷新」。

## 观测地点与「今晚看什么」

1. 右栏切到「观测 OBSERVE」→ 设置观测地点（三种方式任选）：
   - 📍 使用我的位置（浏览器定位，需允许权限；localhost 视为安全上下文）
   - 城市预设下拉（北京/上海/广州/深圳/成都/西安/杭州/南京/武汉/哈尔滨/乌鲁木齐/拉萨）
   - 手动输入经纬度，或 **Alt + 点击地球表面** 直接选点
   地点会存到 localStorage，下次打开自动恢复。
2. 设好后立即得到两份清单：
   - **当前可见**：仰角 > 10° 且被阳光照亮的目标，按推荐分排序，显示仰角/方位/斜距/估算星等/可见等级
     （肉眼可见 ≤ 4.5 等、双筒 ≤ 7 等、望远镜 > 7 等）。
   - **未来 6 小时推荐过境**：正在过境最多 6 条 + 待看 4 条，显示倒计时、最高仰角、方位、时长、推荐理由。
3. 点击任意条目 → 选中该卫星（画轨道 + 地面轨迹），详情卡出现「观看 VIEWING」：
   当前仰角/方位/距离/是否被照亮/估算星等/下一次过境（时间 · 最高仰角 · 时长）。
4. 地球上的观测点用金色标记 + 1200km 本地地平圈表示；打开「仅高亮可见卫星」后，可见目标会被放大、其余缩小。

计算口径（全部在本机完成，不依赖第三方接口）：
- 仰角/方位/斜距：由 SGP4 得到的 ECI 位置经 GMST 转到 ECEF，再做站心 ENU 投影；
- 是否可见：除仰角 > 0 外，还要判断卫星是否被太阳照亮（地影圆柱模型），黑夜里地影中的卫星是看不见的；
- 过境：以 30s 步长扫描 6 小时，找到地平线穿越后用二分法细化到秒级，给出 AOS/LOS/最高仰角/方位/时长；
- 星等为**估算**（按目标类型给定基准亮度 + 距离修正），不是测光结果；GEO 常驻天际、MEO 长时间可见，
  因此不进入「过境」推荐（它们会出现在「当前可见」里）；
- 推荐分会同时考虑最高仰角、是否为空间站等大目标、是否被照亮、当地天空亮度（白天/暮光/夜空）。

## 数据来源与判定口径

| 数据 | 来源 | 用途 |
| --- | --- | --- |
| TLE 两行轨道根数 | CelesTrak GROUP=active | SGP4 位置递推 |
| SATCAT 卫星目录 | CelesTrak satcat | 国家/机构、发射日期、轨道根数、运行状态 |

- 服务端合并成 data/catalog.json（10MB，gzip 1.27MB）并缓存 6 小时；断网自动回退旧缓存。
- 国家/组织取 SATCAT 的 OWNER 字段（US / PRC / CIS / UK / SES / ITSO …），99 个代码全部有中文名与国旗。
- **所属公司与任务类型是按「名称 + 运营方 + 轨道 + 发射年份」规则推断的**，不是官方标注：
  - 通信类：名称匹配 STARLINK / ONEWEB / KUIPER / 千帆 / 国网 / INTELSAT / SES / EUTELSAT 等；
  - 导航类：GPS/NAVSTAR、GLONASS、GALILEO、北斗/BD、QZSS、NavIC；
  - 对地观测：SENTINEL、LANDSAT、GF 高分、ZY 资源、YAOGAN 遥感、PLANET/FLOCK/SKYSAT、ICEYE/CAPELLA 等；
  - 气象：GOES/NOAA/JPSS、风云 FY、Himawari、Metop、Meteosat；
  - 军事：NROL、USA-2xx、遥感系列等（**商用星座不会被标成军用**）；
  - 科学：ISS、天和、哈勃、JWST；技术试验：试验星、CubeSat。
  - 当前 85% 为高置信命中；1,669 颗（10.5%）名称无特征，诚实归入「其他 / 未分类」。
- CelesTrak 对同一分组有 2 小时下载间隔，短时间反复刷新会提示「未更新」，属正常限流。

## 操作

- 左键拖拽旋转、滚轮缩放、双击空白复位；点击卫星选中/取消。
- 密集区域点击 → 弹出候选列表，点一行即选中该卫星。
- 悬停：白色准星 + 名称/国家/高度标签（图层「标签」可关）。
- 键盘：C 切换配色（国家 → 任务类型 → 轨道类型），空格 暂停/继续，Esc 取消选中。
- 左栏：搜索、轨道类型、任务类型、国家/组织；右栏：概览统计、任务类型分布、国家 TOP、目标详情。

## 技术要点

- 零构建：原生 ES Module + importmap，无打包器、无 npm 依赖。
- 后台推算：15,927 条 TLE 解析为 satrec 后由 Web Worker 每 200ms 批量递推（单次约 20ms），主线程只渲染。
- 坐标：ECI → ECEF（含 GMST）→ Three.js Y-up，地面轨迹与卫星位置严格一致。
- 拾取：屏幕空间投影 + 射线-球体遮挡判定（地球背面不可选）+ 邻近候选列表。
- 配色：国家 16 色全息调色盘 / 8 类任务颜色 / 轨道类型颜色，C 键切换。
- 调试：控制台 __MIRROR.state、__MIRROR.pixelStats()、__MIRROR.frameAscii()（无头环境自检）。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示「数据服务不可用」 | 确认 node server.mjs 在运行、端口未被占用 |
| 端口 5180 被占用 | node server.mjs --port 5181，访问 5181 |
| 卫星数量为 0 | 删除 data/catalog.json 后重启，重新联网抓取 |
| 刷新提示「未更新」 | CelesTrak 2 小时限流，等待后再试 |
| 卡顿 | 缩小窗口 / 关闭 Bloom / 降低 composer 像素比 |
